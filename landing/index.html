How it works

One URL in, a reel of clips out

A background job walks each video through four stages, and the web UI polls live status the whole way.

1

Download

Fetch the source video and extract a clean audio track to work from.

2

Transcribe

Turn speech into a timed transcript — the backbone for highlights and captions.

3

Highlight

Score the transcript for hook, payoff and retention, and pick the strongest moments.

4

Render

Reframe, caption, grade and export each clip in parallel — ready to post or edit.

Run it locally

Up in one command

Everything runs on your own machine — the virtualenv ships with every dependency, so there's nothing to install first.

  1. 1
    Start the server — from the project root, launch the FastAPI app with the bundled virtualenv.
  2. 2
    Open the UI — visit the local URL; the pre-rendered demo job loads instantly, no API key needed.
  3. 3
    Paste a URL — add a YouTube link, watch the live pipeline, then download, refine, or publish each clip.
Highlight picking & NL edits call the Claude API — export ANTHROPIC_API_KEY before starting (model claude-opus-4-8). The demo job and existing clips work without it.
bash — clipforge 
# start the server (from the project root)
cd /home/hakuza/clipforge
/home/hakuza/venv/bin/python -m uvicorn server:app \
  --host 127.0.0.1 --port 8800

# then open the UI
http://127.0.0.1:8800/
